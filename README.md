# Gomdor (곰도르)

물리학도 출신 개발자의 **물리 예제 + 웹개발 공부 + 개인 철학 블로그** 사이트.

## 목적
1. **물리 예제**: 포물선 운동, 충돌, 중력장 등을 JavaScript Canvas로 시뮬레이션한다.
2. **웹개발 공부**: HTML / CSS / JavaScript를 직접 만들어 보며 익히고, 이후 Node.js로 확장한다.
3. **블로그**: 개인 철학과 생각을 글로 남긴다. (예정)

## 실행 방법
별도 설치 없이 브라우저에서 실행되는 정적 웹사이트다.

- VS Code의 **Live Server** 확장으로 `index.html`을 연다. (포트 5501, `.vscode/settings.json`)
- 일부 예제(`소수박스` 등)는 ES 모듈(`import`)을 사용한다. 파일을 더블클릭해서 열면(`file://`) 동작하지 않으므로 반드시 Live Server 같은 로컬 서버로 연다.

## 파일 이름 규칙
| 규칙 | 기호 | 예시 |
|---|---|---|
| 합쳐서 **하나의 단어(개념)**가 되는 경우 | `_` | `jump_cat`, `prime_box` |
| **서로 다른 단어(부분)**를 이어 붙이는 경우 | `-` | `button-jump`, `example-prime_box` |

- 모두 **영어 소문자**로 쓴다. (웹 서버는 대소문자를 구분한다.)
- **공백과 한글은 쓰지 않는다.** (URL에서 깨지거나 링크가 끊길 수 있다.)
- 기존 파일들은 아직 이 규칙을 따르지 않는다. 앞으로 조금씩 바꿔 나간다.
